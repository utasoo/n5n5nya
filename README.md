# 🌸 JLPT N5 한자·단어 마스터

나만의 JLPT N5 학습 사이트입니다.

## 주요 기능
- JLPT N5 한자와 단어 학습
- 단어 검색 및 분류별 확인
- 학습 진도와 암기 상태 기록
- 한자·단어 손글씨 연습
- 객관식 퀴즈와 오답 노트
- 손글씨 받아쓰기 시험 및 자동 채점

## 사이트 주소
https://utasoo.github.io/n5n5nya/

## GitHub Pages 설정
1. 저장소의 **Settings → Pages**로 이동합니다.
2. **Deploy from a branch**를 선택합니다.
3. Branch는 `main`, 폴더는 `/(root)`로 설정하고 **Save**를 누릅니다.
4. 저장소 최상위에 `index.html` 파일이 있어야 사이트가 표시됩니다.

## 참고
- 학습 기록은 사용 중인 브라우저의 로컬 저장소에 저장됩니다. 다른 기기나 브라우저와 자동으로 동기화되지 않습니다.
- 일부 글꼴과 스타일은 인터넷 연결을 통해 불러옵니다.
